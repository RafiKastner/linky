API Docs

The api is free cause I don't expect many people to use this.

To get a link shortened, GET at /api/shorten?url={{'{}'}} where {{'{}'}} is the link to be shortened. This returns a JSON where the 'shortUrl' property is the alphanumeric code for the url.


To get the link back, GET at /api/redirect?code={{'{}'}} where {{'{}'}} is the code from before. This returns a JSON where the 'originalUrl' property is the url string.
